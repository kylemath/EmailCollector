⚙️ Gmail API Setup Instructions

            
            

                
Step 1: Create Google Cloud Project

                
    
                    
  1. Go to Google Cloud Console
    2. 
                    
  2. Create a new project or select an existing one
    3. 
                    
  3. Note your project name
    4. 
                


                
Step 2: Enable Gmail API

                
    
                    
  1. In the Cloud Console, go to "APIs & Services" → "Library"
    2. 
                    
  2. Search for "Gmail API"
    3. 
                    
  3. Click "Enable"
    4. 
                


                
Step 3: Create OAuth 2.0 Credentials

                
    
                    
  1. Go to "APIs & Services" → "Credentials"
    2. 
                    
  2. Click "Create Credentials" → "OAuth client ID"
    3. 
                    
  3. If prompted, configure the OAuth consent screen:
                        
      
                            
    • User Type: External
      • 
                            
    • Add your email as a test user
      • 
                            
    • Scopes: Add "https://www.googleapis.com/auth/gmail.readonly"
      • 
                        
    
                    
    4. 
                    
  4. Application type: "Web application"
    5. 
                    
  5. Authorized JavaScript origins: Add your local URL (e.g., http://localhost:8000 or file://)
    6. 
                    
  6. Click "Create"
    7. 
                    
  7. Copy your Client ID
    8. 
                


                
Step 4: Configure the App

                
    
                    
  1. Open config.js in this directory
    2. 
                    
  2. Replace YOUR_CLIENT_ID_HERE with your actual Client ID
    3. 
                    
  3. Replace YOUR_API_KEY_HERE with your API Key (from Credentials page)
    4. 
                    
  4. Save the file
    5. 
                


                
Step 5: Run a Local Server

                
For security reasons, Gmail API requires HTTPS or localhost. Run a local server:

                

                    python3 -m http.server 8000
                

                
Then open http://localhost:8000 in your browser


                

                    ⚠️ Important:
                    
    
                        
  • Keep your credentials private - never commit config.js to public repos
    • 
                        
  • Add test users in OAuth consent screen if app is not verified
    • 
                        
  • Gmail API has daily quota limits (check Google Cloud Console)
    •
